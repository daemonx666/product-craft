# 规格文档模板

照这个结构写。尖括号是要替换的内容；不适用的章节写“无”或删掉。

```markdown
---
title: <功能名>
status: draft            # draft → confirmed → in-progress → done
created: <YYYY-MM-DD>
project: <项目名>
---

相关现有功能：
| 功能 | 位置 | 现在怎么工作 | 与本需求的关系 |
|---|---|---|---|
| <名称> | `<path>` | <数据、流程、界面，一两句> | 复用 / 扩展 / 修改 / 冲突 |

## 2. 对标参考
| 产品 | 做法 | 借鉴 | 不采用 |
|---|---|---|---|

结论：<一句话>

- G1 <可衡量的目标>

- <明确排除的内容>

  1. <步骤>
  2. <步骤>

- 描述：<做什么>

  - [ ] Given <前提> When <操作> Then <结果>

……
```
